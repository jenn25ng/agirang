# 채이네 오픈하우스 초대장

2026년 9월 13일 오픈하우스 초대장 페이지. **아기랑 앱과는 무관한 일회성 페이지**라서
이 폴더 하나만 지우면 앱에는 아무 영향이 없습니다.

- 페이지: `index.html` (단일 파일, 외부 스크립트 의존 없음)
- 주소: `https://<사용자>.github.io/agirang/chaei-open-house/`

## 9월 10일 0시 공개

`index.html`의 `OPEN_AT` 상수(`2026-09-10T00:00:00+09:00`)를 기준으로 두 가지가 바뀝니다.

| | 9/10 0시 이전 | 이후 |
|---|---|---|
| 주소 | 가려짐 · 남은 시간 표시 | 공개 |
| 초인종·현관문·커튼 순서 | 진행 | 건너뛰고 초대장이 바로 열림 |

**주의 — 이 가림막은 연출이지 보안이 아닙니다.** 정적 페이지라서 주소 문자열은 9/10
이전에도 HTML 소스 안에 들어 있습니다. 브라우저에서 소스 보기를 하면 읽을 수 있고,
기기 시계를 앞당겨도 열립니다. 그 전까지 정말 아무도 알면 안 되는 정보라면 서버가
필요하거나, 9/10에 주소를 직접 커밋해 넣는 방식이어야 합니다.
