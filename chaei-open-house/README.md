# 채이네 오픈하우스 초대장

2026년 9월 13일 오픈하우스 초대장 페이지. **아기랑 앱과는 무관한 일회성 페이지**라서
이 폴더 하나만 지우면 앱에는 아무 영향이 없습니다.

- 페이지: `index.html` (단일 파일, 외부 스크립트 의존 없음)
- 주소: `https://<사용자>.github.io/agirang/chaei-open-house/`

## 보내기 전에 채울 것

`index.html` 안의 두 곳이 아직 `○○○` 자리표시자입니다. 채우지 않으면 페이지 상단에
경고 박스가 뜹니다.

- `id="addr"` — 아파트 동·호수
- `id="phone"` — 연락처

페이지에서 **✏️ 내용 고치기**로 고친 내용은 화면에서만 바뀌고 파일에는 저장되지 않습니다.
확정된 문구는 `index.html`을 직접 고쳐주세요.
